## 🚀 快速开始

### 环境要求

- Node.js 18+

## 📁 添加新项目

只需将项目放入 `public/projects/` 目录，系统会自动扫描并生成展示：

```
public/
└── projects/
    └── my-awesome-project/
        ├── index.html    ← 入口文件（标题将作为卡片名称）
        └── cover.png     ← 封面图（可选，推荐 16:9 比例）
```

### URL 规则

项目以 `/projects/<目录名>/` 的**目录形式 URL** 对外暴露，去掉了 `index.html`。
本地 `npm run dev` 由 `vite.config.js` 中的中间件补齐目录解析，生产环境由静态托管
（Cloudflare Pages 等）原生处理，两边行为一致。

**目录名就是 slug**，请使用有语义的小写短横线命名（如 `neon-pulse`），因为它会直接
出现在网址和文件名中。入口必须命名为 `index.html` 或 `index.htm`，否则目录 URL 无法解析。

### 项目元数据

系统会自动读取 HTML 中的 `<title>` 作为项目名称。也可以在项目目录下放一个
`project.json` 覆盖默认值：

```json
{
  "title": "展示名称",
  "slug": "url-slug",
  "tags": ["game", "interactive"],
  "cover": "cover.jpg",
  "order": 10
}
```

| 字段 | 说明 |
|------|------|
| `title` | 覆盖 `<title>`，不改文件名也能换展示名 |
| `slug` | 覆盖 URL slug。改名后脚本会自动在 `public/_redirects` 生成 200 映射，无需手写 |
| `tags` | 覆盖标签列表；不写则回退到 HTML 里的 `data-tags`，再回退到 `["project"]` |
| `cover` | 指定封面文件名；不写则自动探测 `cover.png/jpg/jpeg/webp/avif` |
| `order` | 数字越小越靠前；不写的排在后面，同组内按 slug 字母序 |

标签也可以直接写在 HTML 上（`<meta name="project-tags">` 同样支持）：

```html
<html data-tags="animation,game,interactive">
```

### 旧地址兼容

`public/_redirects` 负责永久跳转，已内置历史占位目录名（`project-a` 等）到新 slug 的
301 规则，**请勿删除**。脚本只会重写自己托管的
`# >>> generated by scripts/generate-projects.js >>>` 区块，手写规则不受影响。

## 🔗 分享与深链

主站状态会同步到地址栏，方便收藏与分享：

| 参数 | 作用 | 示例 |
|------|------|------|
| `p` | 直接打开指定项目的预览面板 | `/?p=neon-pulse` |
| `q` | 预填搜索关键词 | `/?q=可口可乐` |
| `tag` | 预选标签分类 | `/?tag=game` |

打开/关闭预览会写入一条历史记录，浏览器返回键即可关闭面板；搜索与标签变化使用
`replaceState`，不会污染后退栈。`p` 指向已下线的项目时参数会被自动清除。

根页面已声明 `canonical`，因此上述查询参数不会被搜索引擎当作重复页面收录。

## 🎨 设计亮点

### 色彩系统

采用现代渐变色彩方案：

```
Indigo (#6366f1) → Purple (#a855f7) → Pink (#ec4899)
```

### 动画效果

- **悬停反馈**: 卡片上浮、缩放、阴影变化
- **页面过渡**: 淡入淡出、滑入滑出
- **加载状态**: 脉冲光晕、旋转动画
- **按钮交互**: 渐变背景、图标旋转

```css
背景：#030712 → #0e1024
强调色：#6366f1 → #a855f7
```

## 📂 项目结构

```
h5-agg/
├── public/
│   ├── favicon.svg          # 网站图标
│   ├── projects/            # H5 子项目目录
│   ├── projects.json        # 自动生成的项目清单
│   └── _redirects           # 旧地址 301 跳转规则
├── scripts/
│   └── generate-projects.js # 项目扫描脚本
├── src/
│   ├── components/
│   │   ├── Header.jsx       # 顶部导航栏
│   │   ├── Sidebar.jsx      # 侧边分类栏
│   │   ├── ProjectCard.jsx  # 项目卡片组件
│   │   ├── ProjectListRow.jsx # 项目列表行组件
│   │   └── PreviewPane.jsx  # 预览面板组件
│   ├── App.jsx              # 主应用组件
│   ├── main.jsx             # 入口文件
│   └── index.css            # 全局样式
├── index.html               # HTML 模板
├── package.json             # 项目配置
└── vite.config.js           # Vite 配置
```

## 🌐 部署

### Cloudflare Pages

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 进入 Workers & Pages → 创建应用 → Pages
3. 连接 GitHub 仓库 `Chenming00/Mings-project`
4. 配置构建设置：
   - **框架预设**: Vite
   - **构建命令**: `npm run build`
   - **输出目录**: `dist`
5. 保存后自动部署

### Vercel

1. 登录 [Vercel](https://vercel.com/)
2. Import GitHub Repository
3. 自动检测 Vite 框架，一键部署

### Netlify

1. 登录 [Netlify](https://netlify.com/)
2. 连接 GitHub 仓库
3. 配置构建命令和输出目录
